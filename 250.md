Fixes #250.

`deploy/Dockerfile` now upgrades pip before `pip install -e /app/server`. This is the workaround pp confirmed on OrbStack: the pip bundled with `python:3.12-slim` can't parse OrbStack's `7.2.12-orbstack-…` kernel version and aborts.

### ⚠️⚠️⚠️ Not built locally
Docker wasn't running on the machine that prepared this PR, so the image was **not built here**. CI only validates the compose file and doesn't build the image, so please run `docker compose -f deploy/docker-compose.yml up --build` once on OrbStack (and on Docker Desktop if you have it) before merging.

The pip upgrade happens at build time only. The runtime container still has no outbound access.
