Fixes #253.

### What changes
- **"‹ Photos" back link** at the top of the Admin sidebar, above a small "Admin" title, in the same place as a back button in System Settings. It's a real link to `/`, so middle-click and the browser behave normally.
- **Phone widths:** the back link and the "Admin" title share one row above the scrolling section strip, with a 44 px tap target.
- **Esc** goes back to the library, except when a dialog is open (for example Replace library) or focus is in a text field or select, where Esc would throw away what was typed.
- **Browser Back** already worked, because `/admin` is a full page load from the account menu. Nothing changed there.
- The **"This account is not an admin."** screen also gets the back link, so a non-admin who lands on `/admin` isn't stuck there.

### Tests
`AdminApp.test.tsx` covers the back link in the sidebar and on the not-an-admin screen, Esc navigating to `/`, and Esc being ignored inside a field or while a dialog is open. The full web suite, `tsc` and `check-colours` pass.

The link uses `cursor: default`, following the app-wide cursor rule proposed in #255.
