Fixes #263.

### What changes
- **No library → welcome screen** (`WelcomeScreen.tsx`, replaces `LibraryPlaceholder.tsx`) on desktop and phone: the library icon, "Welcome to Photos", and then
  - **admins:** "Add a photo library to start browsing…", an **Add a Library** button that opens `/admin`, and a hint for the case where a library exists but isn't assigned to them ("Give your account access to it under Admin → Access");
  - **everyone else:** "There are no photo libraries for you yet. Ask your admin to add one or give you access."
- **No more "lands in a later phase"** anywhere. `TabPlaceholderScreen` (Albums, Search) and `MorePlaceholderScreen` (People, Places, media types) now take a message:
  - no library: "Nothing here yet. Photos appear once a library has been added.";
  - library updating: "Back once the library has finished updating.";
  - unknown media type in the URL: "This list doesn't exist."
- **Friendly per-view empty states, like Photos:** the whole library says "No Photos or Videos". Smart albums say "No Videos", "No Favorites", "No Screenshots", "No Live Photos", "No RAW Photos", and so on (`albumText.ts`).
- **Years and Months are disabled** (dimmed, not clickable) while the library has no photos: on desktop when the unfiltered list comes back empty, on phone when `/summary` has no years.
- **Stray "Library" caption removed:** `LibrarySwitcher` rendered the literal fallback "Library" under the account row when the user had no library. It now renders nothing in that case, and with one library it shows that library's name.

### Tests
New tests in `DesktopShell.test.tsx` (admin welcome with the link to `/admin`, user welcome without it, no switcher caption, no "later phase" text) and `MobileShell.test.tsx` (welcome plus the Albums tab's empty message). `MobileLibrary.test.tsx` now also asserts that Years/Months are disabled for an empty library. Tests that matched the old "No photos yet." copy were updated. One test that switched to Months on an empty library now uses Days, because Months is correctly disabled there. The full suite, `tsc` and `check-colours` pass.
