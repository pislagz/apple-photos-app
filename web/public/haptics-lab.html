Haptics lab

T1 · Visible native switch (baseline)

Tap the switch a few times. If this gives no tick, haptics are off on this phone (Settings → Sounds & Haptics → System Haptics) and nothing below can work.

T2 · Button with an invisible switch on top

Looks like a normal button; your finger actually toggles a transparent switch. This is the method that still works on iOS 26.5+ (direct tap).

Tap me

T3 · Filmstrip: tap a thumbnail (invisible switch on each)

Tap single thumbnails: tick? Then swipe the strip starting on a thumbnail: does it still scroll smoothly, and does a swipe wrongly tick?

T4 · Filmstrip: tap a thumbnail (label forwards tap to hidden switch)

Same strip, but each thumbnail is a <label> for a hidden switch (the ios-haptics library method). Tap: tick? Swipe: scrolls fine?

T5 · Code-triggered tick on tap (expected dead on iOS 26.5+)

A normal button whose click handler calls label.click() on a hidden switch. Worked before iOS 26.5; Apple reportedly patched it.

T6 · Tick while scrolling (like iOS Photos filmstrip)

Swipe the strip. Code tries to tick each time a new thumbnail snaps to the centre. Expected: no tick on iOS 26.5+. This is the one pp asked about.

T7 · Long-press (like entering Select)

Press and hold the button ~0.5 s. Code tries to tick when the hold is recognised. Also note if a tick comes only when you lift the finger.

Hold me

T8 · Vibration API (Android only)

Calls navigator.vibrate(10). iPhone has no Vibration API; this is here so the same page reports what Android does.
